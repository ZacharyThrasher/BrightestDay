# Brightest Day - intent golden corpus: "what the player MEANT" -> what the ring should build.
# Used to measure per-category accuracy of the phrase resolver (bd_lexicon). Expectations describe the
# correct INTENT, not whatever the resolver outputs today; a failing line is a real gap (or a line to fix).
#
# Line format:   category | phrase | expectations
#   - '#' starts a comment line; blank lines are ignored.
#   - phrase: exactly as typed. A leading '~' marks a VOICE transcript (whisper-style: lowercased,
#     may carry "." "," "!" and misheard words); resolve it with the spoken path, without the '~'.
#   - expectations: space-separated tokens, ALL must hold:
#       form=Hammer | form=Sword/Axe (any of) | form!=Gun         exact bd_core Form
#       cat=Held|Worn|Creature|Structure|Object (alternatives with /)
#       kind=graft | kind=construct
#       +Mechanic (must have) | -Mechanic (must not have)
#       el=Fire (alternatives with /)
#       scale>=8 | scale<=1           metres, rough bands (tiny <=0.5, human ~1.8, house ~8, kaiju >=15)
#       n>=3 | n<=1                   construct count
#       target=Ethan | target=none    roster player the phrase is aimed at. A space inside a roster name
#                                     is written '_' here (target=Big_Tony); compare ignoring case and
#                                     treating '_' and ' ' alike (Alex_99, xX_Nova_Xx keep theirs).
#       via=onto|at|near|around|hunt  delivery toward the target
#       sig=Domain|Beam|Transformation|Summon | sig=none
#       refer=it | refer=again
#       name~text                     display name contains text (case-insensitive, one word)
#       mount=any | mount=Vehicle     the construct rides a mount (of that form)
#       incant=<power id>             power incantation (assets/powers.ron)
#       rush                          stand rush ("ORA ORA ORA")
#
# Roster used by the test (other players in the match):
#   Ethan, Jake, Sam, Alex_99, Mia, Big Tony, xX_Nova_Xx, DragonSlayer, Zoe
# A name only targets after a verb/preposition aimed at someone ("dragon on sam" -> Sam, not DragonSlayer).
#
# Categories: owner, target, voice_target, popculture, everyday, verbs, combos, signature, pokemon,
#             refer, voice, collisions, name_move, piloting.
